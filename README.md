# Програмний проєкт 2, варіант 6: скалярний добуток

Максимов Гліб, група К-28

Дослідження швидкодії скалярного добутку (`std::inner_product` / `std::transform_reduce`):

1. бібліотечний алгоритм без політики;
2. бібліотечний алгоритм з політиками `seq`, `unseq`, `par`, `par_unseq`;
3. власний паралельний алгоритм для різної кількості потоків K.

Рівні оптимізації: `/Od` та `/O2` (конфігурація Release).

## Збирання

Компілятор: MSVC (Visual Studio 2022 Build Tools), `/std:c++20 /EHsc /MD`.

```
cl /std:c++20 /EHsc /MD /O2 main.cpp
cl /std:c++20 /EHsc /MD /Od main.cpp
```

## Запуск

```
main.exe gen [dir]            :: згенерувати вхідні файли (за замовчуванням у папку data)
main.exe run <label> [dir]    :: запустити експерименти, <label> (O2 або Od) виводиться в заголовку
```

Приклад:

```
main.exe gen
main.exe run O2
```

Вхідні файли не лежать у репозиторії через розмір (до 52 МБ кожен). Команда `gen` створює їх із фіксованим seed, тому дані завжди однакові.

## Формат вхідних файлів

Для кожної довжини N (10 000, 100 000, 1 000 000, 10 000 000) є два файли: `a_<N>.txt` і `b_<N>.txt`.

- перший рядок: N, кількість елементів;
- далі N рядків: по одному цілому числу зі значенням від -1000 до 1000.
